- 對象：凍結 baseline `tests/baseline-2026-08-12.json`（6,295 列，sha256 見 plan.md 開頭）
- 目的：在 `search.js` 改動**之前**，以第三支獨立腳本算出 `EXPECTED_COUNTS` 的名稱數字，

## 3. 超集合性質（不得引入漏檢）

從真實 `中文品名`／`英文品名` 隨機切 3,000 個子字串當查詢（LCG 固定 seed），
對每個查詢比對全量：**舊規則命中 2,818,361 次，新規則遺失 0 次**。
自動化版本為 `tests/search.test.mjs` 的 A19c（決定性取樣）。

推論（非實測）：整串 `Q` 是某欄子字串 ⇒ `Q` 依空白切出的每個詞也是該欄子字串；
NFKC 兩側對稱套用，CJK／ASCII 範圍內不改變子字串關係。實測 0 遺失與此一致。

## 附錄 A：具名查詢腳本（`node m2.mjs <查詢>...`）

```js
import fs from 'node:fs';
const rows = JSON.parse(fs.readFileSync('tests/baseline-2026-08-12.json','utf8'));
const oldN = s => String(s??'').toUpperCase();
const newN = s => String(s??'').normalize('NFKC').toUpperCase().replace(/\s+/g,' ').trim();
const oldHit=(r,q)=>{const raw=String(q).trim(),Q=oldN(raw);return oldN(r['中文品名']).includes(Q)||oldN(r['英文品名']).includes(Q)||String(r['許可證字號']).trim().includes(raw)};
const newHit=(r,q)=>{const ts=newN(q).split(' ').filter(Boolean);const f=[r['中文品名'],r['英文品名'],r['許可證字號']].map(newN);return ts.every(t=>f.some(x=>x.includes(t)))};
for (const q of process.argv.slice(2)) {
  const o=rows.filter(r=>oldHit(r,q)), n=rows.filter(r=>newHit(r,q));
  const lost=o.filter(r=>!n.includes(r));
  console.log(JSON.stringify(q),'old',o.length,'new',n.length,'lost',lost.length, n.slice(0,3).map(r=>r['許可證字號']+' '+r['中文品名']).join(' | '));
}
```
