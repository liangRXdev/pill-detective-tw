## Codex 覆審修正的執行期驗證

### C1 — 部署新版模組後，**首次**重載即取得新版

在 `app.js` 尾端加一行 `window.__SW_C1_PROBE = 2;`（**`sw.js` 完全未動**，模擬「只改前端」），
重載一次：

```
probeOnFirstReload   : 2         ← 拿到新版，不是舊快取
swStillControlling   : true      ← SW 沒有換版，仍是同一個
shellCacheAlsoUpdated: true      ← shell 快取同步被刷新
```

改回 stale-while-revalidate 的話這一格會是 `null`（要第二次重載才會變 2），
且會與已經是 network-first 的 `index.html` 形成版本偏移。探針已移除。

### C6 — 橫幅只在**搜尋資料**退快取時出現

以合成的 `OFFLINE_MODE` 訊息分別觸發：

```
base                        : offlineHidden = true
after path=/data/status.json    : offlineHidden = true    ← 不誤報
after path=/data/appearance.json: offlineHidden = false   ← 正確顯示
```

### C3 — 跨版本組合不得把舊狀態檔的檢查日貼到新資料上

把 `source_version = 2026-07-01 / count = 6100` 的舊狀態檔注入快取，
`appearance.json` 維持 `2026-08-10 / 6295`：

```
freshnessText : 資料版本：2026-08-10（TFDA 來源日期）· 收錄：6,295 筆
                每週一自動檢查 TFDA 來源更新
crossVersionSuppressed   : true    ← 沒有顯示「最後檢查」
showsMetaVersionNotStatus: true    ← 版本取自 meta，不是舊 status 的 2026-07-01
showsMetaCountNot6100    : true    ← 筆數取自 meta，不是舊 status 的 6,100
```

### E7 — `status.json` 回 404 時的降級（不得 fail-closed）

把 `data/status.json` 暫時移走使伺服器回 404：

```
fatalHidden : true                 ← 狀態檔壞掉不得阻斷搜尋
barHidden   : false
freshnessText: 資料版本：2026-08-10（TFDA 來源日期）· 收錄：6,295 筆
showsLastChecked: false            ← 只少了「最後檢查」，其餘照常
```

## E5 — network／storage 人工證據

線上完整操作一次（載入 → 搜尋 `FY` → 搜尋 `APO`）後：

```
observedOrigins : ["http://127.0.0.1:8765"]
foreignOrigins  : []                    ← 執行期沒有任何跨源請求
localStorage    : []
cookie          : ""
sessionStorage  : ["__imt_handshake_page_id"]
```

`__imt_handshake_page_id` 是 **Immersive Translate 瀏覽器擴充功能**寫的
（同一個擴充也在 console 丟過 `dynamic-i18n version mismatch` 錯誤），**不是本站**：
清空 sessionStorage 後重載並再次操作，只有這個 key 回來，本站沒有寫入任何一個。

詳細頁的 TFDA 連結（`data.fda.gov.tw`、`mcp.fda.gov.tw`）**只以 `<a href>` 存在**，
未出現在 `performance.getEntriesByType('resource')` 中，符合 §9／F11。
